The program for Project deadline two has been made using LibGDX, and run using gradle. Upon running the program you will be taken to the Home Screen where you can choose to go the setting menu, exit the program or start the game by pressing PLAY. It will take you to the Level Screen allowing you to choose between three levels. For the purpose of this project only Level 1 has been worked on while Level 2 and Level 3 have only been given their background. Furthermore on the Level Screen you also have the option to return to Home Screen.
Once Level 1 has been chosen, it will take you to the screen for Level 1 where the user can press V or L to simulate completion of the level. Pressing V will display the Victory Screen where the user can replay the level, move to next level or return to Level Screen. Pressing L will display Lose Screen where the user can replay the level or go to Level Screen. Additionally, the user can also pause the level to open pause screen, where they can restart level, continue current level or return to Level Screen. This explains the flow of the program created for AP Project DeadLine 2.
